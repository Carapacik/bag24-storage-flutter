# Example configuration

Firebase Dart options contain invalid example credentials and project identifiers. Generate your own environment-specific Firebase configuration locally. Place Google and Huawei JSON configuration and iOS GoogleService-Info plist files in the paths expected by the platform builds; these files are ignored by Git. Other JSON files, including the OpenAPI schema, are retained.

Values containing `EXAMPLE`, zero-only identifiers and `example.com` domains are placeholders, not real credentials. Never use these example credentials in production.
